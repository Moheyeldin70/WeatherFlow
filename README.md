# WeatherFlow — Android Weather App

تطبيق طقس عربي مبني باستخدام Kotlin وJetpack Compose وMaterial 3.

## بناء APK سحابيًا دون Android Studio

أضفت GitHub Actions workflow ليبني ملف APK تلقائيًا على خوادم GitHub.

1. سجّل الدخول إلى GitHub وأنشئ Repository جديدًا (يمكن أن يكون Public أو Private).
2. ارفع **محتويات هذا المجلد بعد فك الضغط** إلى المستودع، مع الاحتفاظ بمجلد `.github` المخفي.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build WeatherFlow APK** ثم اضغط **Run workflow** (أو انتظر البناء التلقائي بعد رفع الملفات إلى فرع `main`).
5. انتظر حتى تنتهي المهمة بنجاح.
6. افتح نتيجة التشغيل، ثم من قسم **Artifacts** نزّل `WeatherFlow-debug-apk`.
7. فك ضغط الملف الناتج، وستجد `app-debug.apk` جاهزًا للتثبيت على Android.

> قد يطلب GitHub تفعيل Actions للمستودع. أول تشغيل يحتاج إلى تنزيل Gradle ومكتبات Android.

## المزايا الحالية
- حالة الطقس الحالية ودرجة الحرارة المحسوسة.
- الرطوبة والرياح ومؤشر UV.
- توقعات الساعة وتوقعات 7 أيام.
- البحث عن المدن عبر Open-Meteo Geocoding.
- وضع فاتح/داكن.
- لون الهوية البرتقالي `#FF6500`.
- واجهة عربية.

## مصدر البيانات
يعتمد التطبيق على واجهات Open-Meteo المجانية ولا يحتاج إلى API Key.
يتطلب اتصال إنترنت. البحث الحالي يعتمد على اسم المدينة؛ GPS غير مفعّل في هذه النسخة.
